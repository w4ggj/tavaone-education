# TavaOne Education — class deck library

This repository now only holds the class presentation decks in `presentations/`.

The admin **Presentation** tab (tavaoneeducation.org/admin/class/) lists the PDFs in that folder and loads them for the classroom TV, so keep the folder at this path on the `main` branch. Add new decks (PDF, plus the PPTX source if you like) to `presentations/`.

The website, Cloudflare Workers and admin live in the `solar-tavaoneedu` repository.
